# Library Management System — Project Plan

## 1. Project Description

The project aims to develop a simple web-based Library Management
System using HTML, CSS, and JavaScript.

The primary focus of this continuous project is to practise
Software Configuration Management.

## 2. Project Objectives

- Build a basic Library Management System.
- Practise version control using Git.
- Collaborate through GitHub.
- Maintain a shared repository throughout all practical sessions.
- Use feature branches and Pull Requests.
- Test changes before integration.
- Maintain project documentation.

## 3. Functional Requirements

### Add Books
Users can add a book by entering its title and author.

### View Books
Users can view all books in the collection.

### Borrow Books
Users can change a book's status from Available to Borrowed.

### Return Books
Users can change a book's status from Borrowed to Available.

### Remove Books
Users can remove books from the collection.

### Search Books
Users can search for books using their titles or authors.

## 4. Team Responsibilities

### Student 1 — SCM Lead
- Create and maintain the shared repository.
- Coordinate branch management.
- Monitor project commits.

### Student 2 — Developer
- Develop the HTML structure.
- Implement the book entry form.

### Student 3 — Developer
- Design the interface using CSS.
- Improve responsive layouts.

### Student 4 — Developer
- Implement JavaScript functionality.
- Handle book operations and statistics.

### Student 5 — Reviewer/Tester
- Prepare test cases.
- Test application functionality.
- Review Pull Requests.
- Report defects.

## 5. SCM Workflow

The team will use the following workflow:

1. Clone the shared repository.
2. Create feature branches from the latest main branch.
3. Implement changes.
4. Commit changes with descriptive messages.
5. Push changes to GitHub.
6. Create Pull Requests.
7. Review the proposed changes.
8. Merge approved changes into main.
9. Test the integrated application.
