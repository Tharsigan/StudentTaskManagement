# Library Management System

## Project Overview

The Library Management System is a simple web-based application
developed as a continuous project for Software Configuration
Management (SCM).

The system allows users to manage books in a library.

## Objectives

- Develop a basic web-based application.
- Practise Git version control.
- Use GitHub for team collaboration.
- Implement feature branches and Pull Requests.
- Maintain project documentation and testing records.

## Features

- Add new books.
- View the book collection.
- Borrow books.
- Return borrowed books.
- Remove books.
- Search books by title or author.
- View total, available, and borrowed book counts.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code

## How to Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open src/index.html in a web browser.
4. Add books and test the available features.

## SCM Workflow

1. Clone the shared repository.
2. Create a feature branch.
3. Make code changes.
4. Commit changes with meaningful messages.
5. Push the feature branch to GitHub.
6. Create a Pull Request.
7. Review and merge approved changes.

## Current Limitations

- Book information is stored in browser memory.
- Data is lost when the page is refreshed.
- The application does not use a database.
- There is no user authentication.

These limitations can be addressed in future development.
